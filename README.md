# 🚀 Munendra5a – React Portfolio Website

This repository contains the source code for **Munendra5a's personal portfolio website**, built using **React, TypeScript, Tailwind CSS and Vite**, and **deployed on Vercel**.

The portfolio highlights my professional experience, technical skills, projects, and certifications, with a clean, responsive, and performance-focused UI.

---

## ✨ Features

* **Hero Section** – Professional introduction with name and role
* **Projects Showcase** – Real-world projects with descriptions and links
* **Skills Overview** – Technologies and tools I work with
* **Certifications** – Professional and technical certifications
* **Contact Section** – Easy ways to connect
* **Dark / Light Mode** – Theme toggle for better accessibility
* **Fully Responsive** – Optimized for desktop, tablet, and mobile
* **Fast Performance** – Powered by Vite and Vercel

---

## 🛠️ Tech Stack

### Frontend

* React
* TypeScript

### Hosting

* **Vercel** (CI/CD with GitHub integration)

## ⚡ Getting Started

### Prerequisites

* Node.js **v16+**
* npm (preferred package manager)

---

### Installation

1. Clone the repository

   ```bash
   git clone https://github.com/Munendra7/Portfolio.git
   ```

2. Navigate to the project directory

   ```bash
   cd portfolio.client
   ```

3. Install dependencies

   ```bash
   npm install
   ```

---

## 🧑‍💻 Development

Start the local development server:

```bash
npm run dev
```

The app will be available at:

```
http://localhost:5173
```

---

## 📦 Build for Production

```bash
npm run build
```

---

## 🚀 Deployment (Vercel)

This project is deployed using **Vercel** with automatic deployments enabled:

* Every push to the `main` branch triggers a new deployment
